# Windrose Roadmap Index

This folder collects phased work, backlog notes, and completion guides for Windrose.

## Roadmap areas

- [Companion State Webserver](companion-state-webserver/README.md) — phased browser/API rollout and deployment notes for the read-only sidecar.
- [Windrose Runtime Control Surface](windrose-runtime-control-surface/README.md) — the live-mutation backlog, operator contract, and possibility atlas for WindrosePlus and future write-capable surfaces.
- [Windrose Fork and Pipeline Path](windrose-fork-and-pipeline/README.md) — the fork/build/pipeline/cutover plan for operating Windrose from this repo.
- [Public Exposure Readiness](public-exposure-readiness/README.md) — release-hardening and documentation cleanup for public sharing.
- [Windrose Core NuGet Publishing](windrose-core-nuget-publishing/README.md) — packaging and publishing guidance for the shared `Windrose.StateWeb.Core` contract layer.

## How to use this folder

Use roadmap pages for work that is still being phased, researched, or gated by future implementation slices.
Once a capability is stable and proven, document it in `docs/features/` and keep the roadmap focused on what remains.
