# Windrose Feature Index

This folder collects the stable feature docs for the Windrose stack.

## Feature areas

- [Server State Observability](server-state-observability/README.md) — log, save, checkpoint, and live dashboard surfaces for exposing dedicated-server state.
- [Windrose Runtime Control Surface Map](server-state-observability/runtime-control-surface.md) — the read-only vs write-capable capability split for observer and operator surfaces.

## Where roadmap work goes

Feature docs should describe what is already proven and safe to depend on.
If a capability is still speculative, phased, or pending operator-contract work, keep it in `docs/roadmaps/` instead.
